# trafmix

Контроллер (малинка / любой Ubuntu) гоняет **разнотипный трафик с лимитом скорости** (UDP-файл,
TCP, HTTP-загрузка, микс) на твои тестовые сервера и отдельно мерит, **живы ли они**. Один
сервер с «шумом», другой контрольный — сравниваешь на таймлайне.

Только для своих серверов. Это нагрузочно-измерительный стенд.

## Раскатка в одну команду

**Панель** (там, откуда рулишь):
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/PonomarevAleksandr/trafmix/main/get.sh) panel
```
**Нода** (на каждый тестовый сервер):
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/PonomarevAleksandr/trafmix/main/get.sh) node
```
Без аргумента — спросит, что ставить. Скрипт сам поставит `git`/`iperf3`, склонирует репо,
поднимет сервис и подскажет следующий шаг. Нужен только `python3` (есть везде).

Панель откроется на `http://<ip>:8744`. У неё **нет своей авторизации** — держи её на внутреннем
IP или за своим VPN/прокси.

## Как пользоваться (3 шага)

1. **+ сервер** — впиши свою ноду: адрес, порт `5201`, а для HTTP-трафика URL `http://<ip>:8745/file`.
   Второй сервер отметь «контрольный» — ему трафик не идёт, только проверка.
2. **+ трафик** на сервере — выбери тип (UDP/TCP/HTTP/микс), скорость и как часто.
3. Смотри карточки: таймлайн доступности за сутки и объём трафика. «Запустить» — прогнать сразу.

**Общий лимит** сверху ограничивает всю скорость разом (одновременно идёт один поток), чтобы не
положить домашний аплинк и не нагрузить сервера. «Пауза» глушит весь трафик.

## Вручную (без curl)

```bash
git clone https://github.com/PonomarevAleksandr/trafmix && cd trafmix
./trafmix up          # панель локально → http://<ip>:8744 (Ctrl+C — стоп)
sudo ./trafmix service   # или как сервис
sudo ./trafmix node      # нода (на сервере)
./trafmix stop        # остановить локальную панель
```

## Что где

```
get.sh             раскатка одной командой (panel / node)
trafmix            локальный скрипт: up / node / service / stop
controller/        панель: trafmix.py (API+планировщик) · runners.py · db.py · static/
agent/httpfile.py  http-источник файла для ноды
```
Стек: Python 3.9+ стандартная библиотека (без pip) + `iperf3` + `curl`. Данные — `controller/trafmix.db`
(sqlite, хранит неделю прогонов и проверок).
